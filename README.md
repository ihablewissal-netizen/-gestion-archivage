# 📁 Gestion d'Archivage - Conseil Provincial Ifrane

Application web développée lors de mon stage au Conseil Provincial d'Ifrane pour la numérisation et la gestion des archives administratives.

### 🎯 Objectif
Remplacer le classement papier par une solution numérique sécurisée pour retrouver rapidement les documents.

### ✨ Fonctionnalités
- Ajout / Modification / Suppression d'archives
- Recherche rapide par référence, date, catégorie
- Classement par service / année
- Authentification sécurisée
- Dashboard administrateur

Développé par Wissal EL BAHI - Stagiaire Développement Digital
